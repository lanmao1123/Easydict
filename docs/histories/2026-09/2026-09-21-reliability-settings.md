# 存储一致性、异步取消与设置体验优化

## 目的与范围

保留已有翻译、截图、OCR、快捷键和剪贴板设置语义，修复检查中确认的问题并改进设置界面。

- `ClipboardStore`：事务性去重，失败保留原记录与图片；删除成功后清理文件；跨调用方操作锁；查询执行失败显式抛出；空白搜索按无过滤处理。
- `ScreenshotDockManager`：旧任务取消不再污染新会话；读音回填校验会话；合并重复布局计算。
- `Task.withTimeout`：传播父任务取消，取消内部任务，保留正常完成、超时和错误传播。
- 设置：原生侧栏键盘导航、分类图标与标题、固定页面切换尺寸和屏幕范围限制；可取消的后台存储统计；保存目录首屏展示、文件格式兼容性与作用域资源释放；服务说明不遮挡列表。

## 验证

- Debug `build-for-testing` 与最终增量 `build` 通过。
- 主要回归：8 个套件 79 项通过。
- AppleScript 调用方：4 项通过，1 项沿用仓库既有禁用规则。
- SwiftFormat lint、构建自带 SwiftLint 与 `git diff --check` 通过；保留既有警告。
- SQLite 触发器故障注入验证回滚和文件保留；父取消测试覆盖忽略取消的 operation 和预取消场景。
