# 避免设备控制授权反复弹出

macOS 27 将辅助功能相关的设备控制能力集中展示。Yaomao 的剪贴板自动粘贴和菜单快捷键会发送模拟输入，用户只授予辅助功能访问时，事件发送权限仍可能缺失。

自动粘贴现在预检授权，并仅在首次实际使用时请求缺失的辅助功能或事件发送权限。后续未授权时提供本地化提示。菜单快捷键在发送模拟事件前进行无弹窗预检；辅助功能状态查询不再主动弹窗。

验证：Swift 源码解析、String Catalog JSON 检查、`git diff --check` 和 Debug 构建均通过。真实 TCC 授权弹窗未在用户正在运行的应用上触发验证；未授权时菜单关闭辅助动作会跳过。
